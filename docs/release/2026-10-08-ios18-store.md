## Implemented behavior

The native Apple button appears beside Google on iOS sign-in and sign-up when both the native capability and API configuration are available. Apple private relay is accepted. Phone entry and verification are optional in Settings.

The API exchanges a one-use Apple code and verifies signature, issuer, bundle audience, expiry and SHA-256 nonce. Apple subjects remain isolated; an email match never silently attaches a provider identity to an existing account. Provider refresh tokens are not persisted or returned to the app.

Deletion requires fresh proof from the same Apple account. Its Apple grant is revoked before the existing fourteen-day recoverable deletion request commits. A revocation failure leaves deletion uncommitted; a fresh sign-in can reach recovery during that window.
